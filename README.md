DecodeLabs Internship - Java Project 2: Student Grade Calculator


Student Grade Calculator

DecodeLabs Internship – Java Project 2

Project Description

This project is a Java application that calculates a student's total marks, average percentage, and grade based on marks obtained in multiple subjects.

Features

- Accepts marks for multiple subjects.
- Calculates total marks.
- Calculates average percentage.
- Assigns grades based on percentage.
- Displays the final result.

Technologies Used

- Java 21
- Scanner
- Loops
- Conditional Statements
- Arithmetic Operations

How to Run

1. Install JDK 21.

2. Open the project in VS Code.

3. Open the terminal.

4. Compile the program using:
   
   "javac StudentGradeCalculator.java"

5. Run the program using:
   
   "java StudentGradeCalculator"
